# FlexDiffusion benchmark definitions

This directory stores small, versioned benchmark configuration files. They are intended to be human-readable, reviewable, and reproducible inputs to the browser-side **Load benchmark…** workflow.

Current schema: `flexdiffusion-benchmark/v1`.

The first reference definition is `cyberdino-sparse-sampler-baseline.json`.

Large generated result corpora do not belong in this directory; keep benchmark definitions small and use the normal review/download workflow for generated PNG/JSON archives.
